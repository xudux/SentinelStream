# SentinelStream

## Overview
SentinelStream is a Real-Time Fraud Detection Engine designed to analyze financial transactions and detect suspicious activities.

## Features
- Real-time transaction analysis
- Fraud detection
- Rule Engine
- ML-based risk scoring
- Redis caching
- RabbitMQ messaging
- Secure transaction logging

## Tech Stack
- FastAPI
- PostgreSQL
- Redis
- RabbitMQ
- Docker
- PyTest
- SQLAlchemy

## Project Structure

app/
docker/
README.md
requirements.txt

## Setup Instructions

1. Clone the repository
2. Create a virtual environment
3. Install dependencies
4. Run the FastAPI application

## Goal

Detect fraudulent transactions with low latency and high throughput.
